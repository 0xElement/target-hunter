# Scope Checklist

- [ ] Target is explicitly authorized.
- [ ] Automation is permitted.
- [ ] Wildcards and exclusions checked.
- [ ] GitHub organization/repositories are explicitly in scope before adding them to `github_orgs`.
- [ ] Program rate limits checked.
- [ ] No credentials/tokens are committed.
- [ ] No customer/PII data is committed.
- [ ] AI leads are manually validated before reporting.
